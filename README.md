## 📖 Overview

The **Advanced Steganography System** is a comprehensive Python-based GUI application that allows you to hide secret data within images and videos using advanced steganography techniques. With built-in password protection (AES-256 encryption), file system explorer, and six additional security tools, this is your complete privacy toolkit.

### Why This Tool?

- 🔒 **Military-grade encryption** - AES-256 with Fernet
- 🎨 **Modern GUI** - Intuitive dark-themed interface
- 🚀 **All-in-one** - Steganography + Encryption + Compression + Encoding
- 🔑 **Password protected** - No one can extract data without the password
- 📁 **File explorer** - Browse, manage, and encode files directly

## ✨ Features

### 🎬 Video Steganography
- Hide text messages inside video files (MP4, AVI, MKV)
- Extract hidden messages with password verification
- Check video storage capacity before encoding
- Analyze videos for hidden data

### 🖼️ Image Steganography
- Hide any file type (PDF, ZIP, images) inside images
- Password-protected extraction
- Image capacity checker
- Visual preview of images

### 🔐 Password Protection
- AES-256 encryption via Fernet
- PBKDF2 key derivation with 100,000 iterations
- SHA-256 password hashing
- Password strength checker
- Secure password generator

### 📁 File System Explorer
- Full file/folder navigation
- Drive selection buttons
- Right-click context menu
- Quick encode/decode from explorer
- File properties viewer

### 🛠️ Advanced Tools (All Unlocked)

| Tool | Description |
|------|-------------|
| 🔧 **File Encryptor** | Encrypt/Decrypt any file with password |
| 🔍 **Steganalysis** | Detect hidden data in files |
| 📊 **Hex Editor** | View and search files in hex |
| 🗜️ **File Compressor** | Compress/Decompress files and folders |
| 🔑 **Password Gen** | Generate strong passwords |
| 📝 **Text Encoder** | Base64, Hex, Binary, URL, ROT13, Morse |

### 💻 System Console
- Execute system commands
- Real-time logging
- Python code execution
- Command history
